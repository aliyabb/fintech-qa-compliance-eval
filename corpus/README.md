# 语料库说明 / Corpus Notes

本目录中的全部条款均为**虚构机构「民信银行 / 民信理财 / 民信支付」的合成语料**，
不对应任何真实金融机构、真实产品或真实费率。

## 为什么使用合成语料（而非真实产品说明书）

1. **消除预训练污染**：模型不可能在预训练中见过这些条款，
   因此"纯 LLM"基线的失败是真实的，RAG 带来的增益可被干净归因。
2. **可控的时效性陷阱**：需要成对的"旧值 / 新值 + 生效日期"来测试模型
   是否会用过时知识作答。真实语料中这种配对只能碰运气。
3. **合规与版权**：可公开发布，不涉及转载他人产品说明书。

## 监管口径条目（F026–F031）

这一组反映的是真实存在的监管原则（投资者适当性管理、禁止收益承诺、
风险揭示义务、投顾资质要求、年化利率明示），用于定义"必须拒答"的判定基准。
条目为原则性表述，非任何具体监管文件的原文引用。

## 字段

| 字段 | 说明 |
|---|---|
| `id` | 片段编号，用于引用命中率的机器校验 |
| `来源` | 虚构文档名 |
| `生效日期` | 用于构造时效性陷阱 |
| `失效日期` | 仅历史版本条目有此字段 |
| `分组` | 分期 / 理财 / 支付 / 监管 |
| `正文` | 条款正文，每条至少含一个可机器校验的具体值 |
